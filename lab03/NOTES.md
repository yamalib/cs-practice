git diff - используется для сравнения изменений между различными состояниями кода
Показывает, что измененно в файле, но ещё не закоммитченно
git show - показывает детали конкретного объекта (автор, дата, описание) и полную разницу его изменений.
git log - показывает хронологический список коммитов. Список коммитов (хэши, авторы, даты, сообщения) .

===========================

log -S"case" (я использовал её, т. к. в моей программе нет def) - эта комманда выдала хэши и названия только тех коммитов, в которых изменилось наличие и / или количество case
git blame - разметила все строки файла (автор, дата, хэш коммита).

===============================================

git restore - Восстанавливает файл из индекса (или из HEAD, если ещё не сделан git add). Незакоммиченные правки при этом безвозвратно заменяются чистой версией из последнего коммита.
git restore --source= - Извлекает состояние файла из конкретной точки в истории (например, из позапрошлого коммита). Текущие правки также стираются, но файл становится равен своей более старой копии.

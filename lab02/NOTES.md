Рабочая папка - это папка на компьютере, где хранятся файлы текущей версии проекта и где вносятся в них изменения.
Индекс - это промежуточная область, которая хранит список файлов и изменений, готовых для включения в следующий коммит.
Коммит - это сохраненный снимок состояния вашего проекта в определенный момент времени, который формирует историю изменений.
Гит и гитхаб различаются следующим:
Гит - это программа, установленная локально на компьютере.
Гитхаб - это облачный сервис для хранения репозиториев.
Использованные команды:
git status - показывает текущее состояние рабочего каталога и индекса в системе Git.
git diff - показывает разницу между состояниями файлов в репозитории.
git diff --staged - показывает разницу между индексом и последним сделанным коммитом, отвечает на вопрос: Что именно попадет в историю, если я прямо сейчас выполню git commit?
